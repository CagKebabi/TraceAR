Jitter = per-frame noise of the marker center (normalized to a 640 px frame), measured via second differences so deliberate camera motion cancels out — only frame-to-frame shake counts. Lower is better.

MindAR is the pioneering open-source web image tracker and takes a different engineering approach; this page exists so the trade-offs can be measured fairly, on your own device, with the exact same metric for both engines.
